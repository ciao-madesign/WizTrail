oppure · Importa da Strava

Strava e sincronizzazione con gli orologi: non ancora disponibili. Carica il file GPX esportato dalla tua app o dal tuo orologio (su strava.com: menu "…" dell'attività > "Esporta GPX").

Funziona con link che scaricano direttamente un file GPX. Le pagine di Strava, Komoot o Wikiloc non sono file: scarica il GPX e caricalo qui sopra. Il link viene aperto dai nostri server per scaricare il file.
